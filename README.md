# TagMarkets

Telegram-бот: сделки по счетам MT5 и события партнёрского кабинета.

## Как устроено

Терминал MT5 работает только под Windows, поэтому историю читает **агент** на
домашнем ПК и отправляет её на сервер сам (исходящими запросами — порты домой
пробрасывать не нужно). **Бот** живёт на сервере круглосуточно и строит отчёты
уже из базы, не дёргая терминал.

```
терминал MT5 ──► agent.py (ПК) ──► webhook_server.py ──► trades.db
                                                             │
                                            bot.py ◄──────────┘ ──► Telegram
                                               ▲
                          api.ibportal.io ─────┘  события кабинета
```

## Файлы

| | |
|---|---|
| `bot.py` | сам бот: отчёты, уведомления, настройки |
| `agent.py` | читает терминал на ПК, шлёт историю на сервер |
| `webhook_server.py` | принимает данные агента и вебхуки |
| `trades.py` | деньги: капитал, профит, проценты, оформление |
| `store.py` | база сделок и месячные итоги |
| `accounts.py` | счета пользователей |
| `partner.py` | состояние, дедупликация, события кабинета |
| `ibportal.py` | доступ к партнёрскому кабинету (JWT) |

**`tools/`** — обслуживание: `selfcheck.py` (проверка логики),
`audit.py` (сверка расчётов на боевых данных), `backup.sh`,
`keeper.ps1` и `TagMarkets.bat` (пульт на ПК).

**`data/`** и **`logs/`** — базы, счета, токены и журналы. В репозиторий не
попадают: там пароли от счетов.

## Проверки

```bash
python tools/selfcheck.py   # логика на выдуманных числах — быстро, без сети
python tools/audit.py       # сверка боевых данных: сходятся ли экраны между собой
```

## Деньги: как считается

- **Капитал** — вложенные деньги. Баланс MT5 усилен плечом Amplify (×24),
  поэтому капитал = баланс ÷ плечо.
- **Профит** лежит на стратегии отдельно, 1:1, и копится, пока его не вывели
  или не реинвестировали.
- **Комиссия брокера** 30% снимается и с прибыли, и с убытка — везде
  показываются суммы «чистыми, на руки».
- **Процент** — доходность каждой сделки к капиталу **на её момент**, сложенные.
  Не «профит ÷ капитал»: при пополнении в середине месяца это занижало результат
  втрое. Месяцы перемножаются, потому что между ними капитал меняется.
