# TagMarkets Mini App

Рабочий интерфейс в стиле Pulse/Aurora. HTML/CSS/JavaScript без сборки;
backend — тот же aiohttp-процесс, который принимает данные агента.

## Запуск

Установить `requirements.txt` в серверное Python-окружение. Добавить только
новую настройку к существующему `.env`, не заменяя файл целиком:

```dotenv
MINI_APP_URL=https://crownfail.shop/tagmarkets/app/
TELEGRAM_BOT_USERNAME=tagmarketgold_bot
```

`python webhook_server.py` подключает API `/api/*` и frontend `/app/`.
Существующий nginx должен передавать `/tagmarkets/` на webhook-сервис со
снятием этого префикса. Для рассылки с вложением в этом location требуется
`client_max_body_size 22m` (фото до 10 МБ, MP4 до 20 МБ). Сервис по умолчанию
слушает только localhost.
При запуске `bot.py` устанавливается стандартная кнопка меню Telegram
«Открыть приложение». Обычная ссылка в браузере не заменяет запуск из бота:
для личных данных требуется подписанный Telegram initData.

## Возможности

| Сценарий | Реализация |
| --- | --- |
| Общая картина | Капитал/профит по валютам, исключение демо из личной суммы |
| Кабинеты | Группировка счетов и отчёт кабинета за выбранный стандартный период |
| Счёт | Капитал, чистый результат, ROI, график, месячная история |
| Периоды | Сегодня, вчера, неделя, предыдущая неделя, месяц, предыдущий месяц, вся история, даты |
| Операции | Сделки/движения, процент к капиталу на дату сделки, страницы по 50, архивные месячные суммы |
| Управление | Добавить, переименовать, удалить личную запись; Invested |
| Уведомления | Общий и отдельные переключатели, единые с ботом; личная лента новых сделок, событий кабинета и сообщений с отметкой прочтения |
| Демонстрация | Отдельный наблюдаемый счёт, показ/скрытие, уведомления |
| Гости | Приглашения с выбором счетов, список, карточка, отзыв только переданных копий без удаления личных счетов гостя |
| Ссылки | Одноразовые ссылки `t.me/...?...`, копирование, отзыв |
| Терминал | Постановка команды перезапуска для собственного счёта |
| Основатель | Статус машин, служебные уведомления, доход сети, рассылка с форматированием, JPG/PNG до 10 МБ и MP4 до 20 МБ |
| Отключение | Удаление своих данных/доступа с подтверждением, кроме основателя |
| Telegram | Проверка подписи initData, BackButton, тема, safe-area |

Новый брокерский трейдинг, реальные переводы/вывод денег не реализованы:
таких поддерживаемых действий в действующем боте/API нет. Не создаются
кнопки, которые обещают несуществующую операцию.

## Общие данные и безопасность

- Счета и настройки — `accounts.py` и существующий accounts.json.
- Лента уведомлений хранится в `partner.py` по Telegram user_id; события
  дедуплицируются, чужие записи нельзя прочитать или отметить прочитанными.
- Капитал, прибыль, месячные итоги — общие `trades.py`/`store.py`.
- Гости, ссылки, настройки — существующая `partner` SQLite KV.
- Сервер всегда читает БД, даже если установлен Python-пакет MetaTrader5.
- Мутации accounts.json защищены межпроцессной блокировкой.
- API принимает только `X-Telegram-Init-Data`; user_id из тела игнорируется.
- Проверяются HMAC, auth_date (24 часа), отозванный доступ и владелец ресурса.
- Пароли не попадают в JSON API, JavaScript, localStorage или preview.
- Передача уже существующего счёта — приглашением. Введённый наугад номер
  не даёт доступ к сохранённой истории. Для переподключения осиротевшей
  истории пока требуется администратор (см. todo.md).
- Обновление интерфейса: раз в минуту (интервал задаёт `refresh_seconds` в
  `/api/bootstrap`, не чаще 30 секунд), пауза в скрытой вкладке/открытом диалоге.
- API возвращает no-store; статические файлы требуют проверки свежести.
- Формат Telegram HTML преобразуется в обычный текст на сервере; клиент
  экранирует пользовательские значения.

Алгоритм авторизации сверён с [официальной документацией Telegram](https://core.telegram.org/bots/webapps#validating-data-received-via-the-mini-app).

## Предпросмотр дизайна

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory web
```

Открыть `http://127.0.0.1:8765/?preview=1`. Используются только вымышленные
записи из `web/preview.json`; изменения отключены. Этот режим не отключает
серверную авторизацию и не может получить реальные данные.
Образец сделок в предпросмотре фиксирован; реальные фильтры периода работают
с серверным API после открытия приложения через Telegram.
Демо-режим не отправляет рассылки. Кнопка ярлыка в обычном браузере показывает
путь через Telegram; нативное добавление доступно только при поддержке клиента.

## Проверки

```powershell
python tests/selfcheck.py
python tests/test_miniapp.py
node --check web/app.js
python tests/ui_smoke.py
```

Тесты создают временные БД и accounts.json. Рассылки реальным пользователям,
удаления реальных данных и брокерские операции не выполняются.
Проверка интерфейса использует локальный Chromium Playwright с вымышленными
данными и проходит ширины 390 и 1280 px, переходы, периоды и выбор кабинета.
При каждом обновлении дополнительно проверяются изменённые сценарии в
мини-приложении на мобильной ширине. Скрипт развёртывания повторяет оба набора
тестов и проверку JavaScript, затем сверяет опубликованные HTML, JS, CSS и
логотип с установленными файлами. Если версия по публичному адресу не совпала
или службы не поднялись, развёртывание откатывается. Реальные операции MT5 и
доставку Telegram это не подменяет: их состояние проверяется отдельно.

## Координация машин

`/agent/claim` выдаёт право опроса одному host+session на 180 секунд.
Успешная `/agent/sync` продлевает срок; heartbeat не продлевает его.
Основная машина (`AGENT_ROLE=primary`) забирает право у резервной сразу, даже
если аренда резерва ещё жива: резерв работает, только пока основная не
отвечает. Остальные ждут текущего владельца. После отказа владелец отдаёт
другой машине окно для перехвата; истёкшие загрузки отвергаются.
Список счетов выдаётся только владельцу через X-Agent-Host/Session.

Устанавливать сначала сервер с endpoint claim, затем агентов.
Основная машина переходит на новый коммит, только когда другая машина
проработала на нём `CANARY_DELAY` (30 минут): в зачёт идёт время между её
первым и последним отчётом, и только пока она остаётся на этом коммите —
упавшая или откатившаяся канарейка обновление не разрешает.
Подробные ограничения нативных MT5-вызовов указаны в todo.md.

## Установка и откат

`tools/deploy_miniapp.py` предназначен только для существующего Linux VPS
`/opt/tagmarkets`. Принимает подготовленный архив исходников, проверяет
синтаксис и тесты в отдельной папке, сохраняет старые файлы и `.env`,
останавливает оба сервиса на время замены, добавляет MINI_APP_URL и
проверяет локальные health/API endpoints. При ошибке возвращает прежний код
и настройки. Пользовательские базы не заменяются архивом исходников.

Перед каждым развёртыванием сохраняется снимок кода, настроек и баз на VPS.
Для просмотра последних десяти **совместимых** версий и отката кода запустите
`tools/rollback-miniapp.bat` в локальной папке проекта. Нужен настроенный SSH-адрес
`tagvps`. Выберите номер версии и подтвердите словом `ROLLBACK`. Сервер перед
откатом сохранит текущий код, остановит оба сервиса, восстановит выбранную
версию и проверит `/health`, интерфейс и защиту API. Если проверка не пройдёт,
он автоматически вернёт предыдущий код. Счета, торговая история, ключ
шифрования и текущие настройки не перезаписываются. Время в списке — UTC.
Ранние версии без поддержки зашифрованных паролей MT5 не предлагаются:
они несовместимы с текущими данными. Снимки исходников и баз находятся в
`/opt/tagmarkets/backup/`; локальный BAT управляет ими через SSH и не скачивает
персональные данные.

Архив нельзя собирать из `.env`, `data/`, `logs/` или локальной памяти.
Автообновление агентов распространяется отдельно через Git. Фактический
статус текущей установки записан в todo.md.

# Защита данных MT5

Пароли MT5 хранятся в `accounts.json` в зашифрованном виде. Ключ находится рядом
с файлом счетов в `accounts.json.key` (или по пути `ACCOUNTS_KEY_FILE`) и создаётся
с правами `0600`. При первом обновлении старые записи мигрируют автоматически.
Для восстановления счетов нужны и файл счетов, и соответствующий ключ;
сохраните ключ в защищённой резервной копии отдельно от исходного кода.
